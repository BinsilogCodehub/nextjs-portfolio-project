# Vince Portfolio — Next.js

A four-page Next.js portfolio website for a school project.

## Pages

- `/` — Home
- `/portfolio` — Portfolio
- `/about` — About
- `/gallery` — Gallery

## Features

- Reusable dynamic `Header` component
- Active navigation button based on the current route
- Responsive design
- Four complete pages
- No external UI libraries required

## Run the project

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open `http://localhost:3000`.

## Build check

Before submitting, run:

```bash
npm run build
```

If the build finishes successfully, the project is ready to submit.

## GitHub

Create a public GitHub repository and push the project:

```bash
git init
git add .
git commit -m "Create Next.js portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Then submit the public repository link together with screenshots of:
- Home
